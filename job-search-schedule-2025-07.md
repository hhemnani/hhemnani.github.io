## Weekly skill focus

The 1.5-hr weekday skill block rotates through the requested skills on a two-week (A/B) cycle. Networking, Python, and GitHub project work appear every week since they're core to both target roles; AWS/Docker and Linux/SQL alternate.

Weekend template both days. Use part of the Saturday free-time block to set up job-search infrastructure: final resume pass, LinkedIn refresh, application tracker spreadsheet, target company list. Sunday evening: review goals for Week 1.

## Notes

- **Job applications**: quality over quantity — 2–3 tailored applications/day beats mass-applying.
- **Volunteer/contract block**: defaults to a self-directed portfolio project (e.g., a home-lab BGP/OSPF simulation, a network monitoring dashboard, or an open-source contribution) until an actual volunteer or contract engagement is secured.
- **Weekends**: no fixed job-application or volunteer-work quota — reserved for rest, with light optional LeetCode/skill time only.
